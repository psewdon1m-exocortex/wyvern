Wyvern 0.0.1 introduces a shared Adapter-based LLM gateway for Exocortex.

Google generation, JSON Schema responses, token counting, streaming and media use scoped client identities. Provider keys live in Volt and are resolved through instance-scoped Kernel grants. Mastermind and Laboratory choose function bindings in their own Settings; the root-only Updater TUI manages Adapters, credentials, grants and runtime lifecycle.

The release includes a signed immutable runtime manifest and verified Updater installer. Updates drain active requests, preserve external configuration, and recover the previous runtime after failed activation. See docs/operations.md for installation, remote HTTPS connections, migration and recovery.

Existing installations need the compatible Kernel/Volt publication contracts and updated consumer packages. Live-provider quota/model support must be checked using the operator's own configured Adapter.
